# 📰 AI Fake News Detection System

An AI-powered multimodal misinformation analysis platform built using Python, NLP, OCR, and Transformer models.

## 🚀 Features

- 📰 News Article Analysis
- ▶️ YouTube Transcript Analysis
- 🖼️ Image/Screenshot OCR Analysis
- 🤖 AI-based Fake News Detection
- 📝 Automatic Text Summarization
- 🔎 Verification Resource Suggestions
- 🌐 Streamlit Web Deployment

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Hugging Face Transformers
- EasyOCR
- Newspaper3k
- Sumy NLP Summarizer
- YouTube Transcript API
- Git & GitHub

---

## 📌 How It Works

1. User uploads:
   - Article URL
   - YouTube URL
   - News Image

2. System extracts text using:
   - Web scraping
   - OCR
   - Transcript extraction

3. NLP summarization is performed.

4. Transformer AI model predicts whether content is:
   - Likely Real
   - Fake
   - Misleading

5. Verification resources are suggested.

This project provides AI-assisted misinformation analysis and should not be considered a final authority for determining truthfulness.
